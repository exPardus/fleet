# Knowledge Index

Startup loads this index and the short current notes in `lessons.md`.
Historical and oversized notes are in `docs/archive/` and are not loaded.

- `lessons.md` — current operator decisions and operating constraints.
- `playbooks/campaign-template.md` — campaign structure; load when planning.
- `playbooks/spawn-etiquette.md` — worker dispatch guidance; load when spawning.
- `projects/claude-fleet.md` — fleet project conventions; load for fleet changes.
- `projects/claude-oracle.md` — oracle project notes; load for oracle work.
- `projects/pmbot.md` — pmbot project notes; load for pmbot work.
- `projects/stupidbox.md` — stupidbox project notes; load for stupidbox work.

Keep new loaded entries factual, pointer-like, and at most 12 lines. Put
historical or oversized entries in `docs/archive/` without rewriting them.
