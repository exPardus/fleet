# w90 — cut what a supervisor boot reads

DONE means: the supervisor boot bundle is measured input-by-input in tokens, the largest inputs are cut so that a boot reads a capped checkpoint and pointers rather than whole journals, and the cap is pinned by a test that fails if the bundle grows past it.
Full measurement table, method, rationale: `docs/lanes/w90-report.md`.

## Measured (this repo's own supervisor files, 2026-09-16)
`_render_boot_bundle()` = 12,271 bytes / ~3,068 tokens before this lane. GOALS.md (7,056B, 57.5%)
+ old journal tail (3,526B, 28.7%) = 86.2%. GOALS.md is operator-owned, not unboundedly growing,
spec-required in full every boot — **left uncut**. The journal tail *was* byte-unbounded:
`SUPERVISOR_BODY_MAX_LINES` caps newline count (3), not per-line length; non-checkpoint kinds
carry no cap at all.

## Cut (v2, after supervisor-gate correction)
v1 inlined only the single newest tail entry — **rejected**: this repo's own 2026-09-16T12:40Z
boot's newest entry was its own just-written BOOT line (zero campaign content), which would have
pointered the checkpoints behind it that step 4 needs. v2: `_select_boot_journal_inline_indices`
inlines bodies only for CHECKPOINT/PROPOSAL kinds, newest-first, min
`SUPERVISOR_BOOT_INLINE_MIN`=2 guaranteed, more while under
`SUPERVISOR_JOURNAL_INLINE_BUDGET_CHARS` (8,000 = 4x per-entry cap); bookkeeping kinds
(BOOT/SEIZED/...) are always pointers regardless of position. On this repo's real tail
(CHECKPOINT, BOOT, CHECKPOINT, CHECKPOINT): BOOT pointers, all 3 CHECKPOINTs inline. Both caps
(`SUPERVISOR_LATEST_ENTRY_MAX_CHARS`=2,000/entry, `SUPERVISOR_BUNDLE_MAX_CHARS`=20,000 whole)
unchanged from v1.
## Cap
`SUPERVISOR_BUNDLE_MAX_CHARS` existed (40,000, whole-bundle backstop) with zero test coverage.
Lowered to 20,000 (~1.6x the measured v2 bundle, ≈12.3KB; total varies a little with the
git-board's live `dirty=<N>`, but the deterministic tail section is +114 bytes over pre-w90),
pinned by `tests/test_boot_bundle_cost.py::TestBundleByteBudget`. Value is the removed ceiling,
not today's savings.
## Scope held
In: `_render_boot_bundle`. Out: handoff verbs, band numbers, spawn prompts, `fleet send`.
