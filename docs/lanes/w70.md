DONE means: the keeper accepts a registered pane only when its command is
`claude`, falls back and pages for shell/dead panes, deletes stale registration
on recreation, and `wave-close` removes only clean lane worktrees whose
branches are merged into base, never using `--force`.

Implemented:

- `wave-close` joins a landed branch to its registered worktree and reads an
  explicit worker substrate or matching `.mcx` record; absent evidence is
  `unknown`, never an inferred `claude`.
- Interface pending-ruling computation ignores supervisor-rendered `sup~*.md`
  files in addition to `lens/`, and still requires no `RULED:` line.
- Keeper registration now reports non-Claude commands once per tick, routes
  shell/dead fallback through `work:fleet`, and clears `state/interface-pane`
  after successful recreation.
- `wave-close` sweeps `wNN/*` linked worktrees after a successful push: clean
  merged entries use `git worktree remove`, then `git branch -d`; unmerged,
  dirty, protected, and failed entries are retained and counted separately.
- Tests cover Claude, shell, dead, absent registration and merged/unmerged/
  dirty worktrees.
