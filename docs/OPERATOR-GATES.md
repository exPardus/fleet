Decisions only Altai can make. **Step 1 of the `fleet` skill's startup ritual reads this file** (`skills/fleet/SKILL.md`) and puts the open items to the operator before any work starts.

Until 2026-07-22 a SessionStart hook injected these into every session automatically. It also injected them into every *unrelated project* on the machine, so it was removed (`docs/specs/terminal-surface.md` D7). Nothing machine-parses this file now — the reader is a human or a model following the ritual, which is why the format below still matters.

Format is load-bearing and pinned by `tests/test_supervisor.py::TestOperatorGatesFile`:

- `- [ ]` is **open** and gets surfaced. It **must be phrased as a question**, ending in `?`.
- `- [x]` is **settled** and is never re-surfaced. Tick it, append the date and the answer, and move it under `## Settled` — never delete it, because a settled gate is the record of a decision, not clutter. *(Corrected 2026-07-27: this bullet used to say "leave it in place" while the file's closing line said "move it here"; every settled gate in the file follows the closing line, so that is the rule.)*
- Keep each line to one decision, front-loaded: the hook shows the line, not this file.
- **`## Open` may legitimately be empty.** A cleared docket is a real state and must not be read — or tested — as a malformed file.

Neither the manager nor any worker may tick a box. An author never promotes its own spec; a reviewer may not ratify one either. Record each answer as a dated line in `knowledge/lessons.md` too — never session memory.
